# DraftOle Examples

## MVP Demo: Todo App

DraftOle の SwiftUI ライク API で生成された Todo アプリケーション。

### 実行方法

```bash
node --experimental-strip-types examples/mvp-demo.ts
```

または npm スクリプト経由:

```bash
pnpm demo:mvp
```

### 出力

`output/mvp_demo/` に以下のファイルが生成されます:

- `index.html` — HTML構造
- `style.css` — スタイルシート
- `script.js` — アプリケーションロジック

### ブラウザで確認

```bash
open output/mvp_demo/index.html
```
