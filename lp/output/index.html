なぜ DraftOle？

三位一体

HTML・CSS・JSを1つのTypeScriptファイルで記述。もう3ファイルを行き来する必要はありません。

型安全

146以上のCSSプロパティすべてに型補完が効きます。タイポや無効な値をコンパイル時にキャッチ。

ゼロランタイム

出力は純粋なHTML/CSS/JS。ランタイム依存なし。どこにでもデプロイできます。

                                import { div, h2, button, Text } from 'draft-ole';

const card = div(
  h2(Text('Hello')),
  button(Text('Click'))
);

card.css.styleManager.style.spacing
  .setPadding('24px');
card.css.styleManager.style.backgroundColor
  .setBackgroundColor('#1a1a1a');
card.css.styleManager.style.border
  .setBorderRadius('12px');

card.jqm.click('handleClick');
